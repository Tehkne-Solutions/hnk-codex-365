## 1. STATUS VOCABULARY

- `SOURCE_DEFINED` — accessible project sources define the operator sufficiently for the current textual practice.
- `SOURCE_PARTIAL` — source defines the operator/concept but not enough to create a canonical visual/technical implementation.
- `HNK_ORIGINAL_REQUIRED` — a missing implementation/reference must be designed and explicitly approved as an HNK-original canonical specification; it must not be presented as recovered historical source.
- `REFERENCE_PENDING` — product/asset publication remains blocked until an explicit canonical decision is versioned.
- `RESOLVED` — a prior ambiguity was decided and merged in canonical content.

## 6. KETHER AUDIO — CONFLICT INVENTORY STATUS

**Status:** `REFERENCE_PENDING`

The synchronized canonical dataset already demonstrates that Kether contains multiple audio vocabularies that must not be collapsed into one number without audit.

Confirmed examples include:

- Day 001 Ordália: `528 Hz` Solfeggio;
- Day 001 QR copy: `Theta / 432 Hz base`;
- Day 002 Ordália: `528 Hz`;
- recurring early QR copy: `Theta / 432 Hz base`;
- Day 006 Ordália: `52 Hz`;
- Day 006 QR copy: `Theta / 432 Hz base`.

### Canonical rule

Until the Kether audio audit is completed, the system must distinguish vocabulary rather than guess equivalence:

- `carrier/base frequency`;
- `binaural difference/beat`;
- `Solfeggio / ritual tone`;
- `ambient layer`;
- `target-state label` such as Theta;
- `unresolved numeric reference`.

The candidate interpretation “432 carrier + 528 ritual layer + Theta target” remains **non-canonical** until the full audit resolves every affected Day, especially the Day 006 `52 Hz` reference.
